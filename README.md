# BRSP – গাড়ি ধোয়ার রোস্টার (React + Vite + Tailwind)

## চালানোর নিয়ম
```bash
npm install
npm run dev       # ডেভেলপমেন্ট সার্ভার (http://localhost:5173)
npm run build     # প্রোডাকশন বিল্ড -> dist/
npm run preview   # বিল্ড করা ভার্সন প্রিভিউ
```

## রোস্টার এডিট করা
`src/data/roster.js` ফাইলে সব তারিখ ও ডিউটির তালিকা আছে। সেখানে এডিট করলেই টেবিল আপডেট হবে।

## ফিচার
- তারিখ অনুযায়ী কার্ড লেআউট (ডেস্কটপে প্রতি সারিতে ৩টি, ট্যাবলেটে ২টি, মোবাইলে ১টি)
- নাম / আইডি / তারিখ / বার দিয়ে লাইভ সার্চ
- প্রিন্ট / PDF ডাউনলোড (ব্রাউজারের Print থেকে "Save as PDF")
- প্রিন্টে সার্চ ও বাটন অটো হাইড
- মোবাইল রেসপনসিভ
