# BRSP – গাড়ি ধোয়ার রোস্টার (React + Vite + Tailwind)

## চালানোর নিয়ম
```bash
npm install
npm run dev       # ডেভেলপমেন্ট সার্ভার (http://localhost:5173)
npm run build     # প্রোডাকশন বিল্ড -> dist/
npm run preview   # বিল্ড করা ভার্সন প্রিভিউ
```

## রোস্টার এডিট করা
`src/data/roster.js` ফাইলে `MEMBERS` (আইডি + পূর্ণ নাম) ও `DUTIES` (তারিখ, বার, আইডির তালিকা) আছে। শুধু আইডি বদলালেই নাম অটো আপডেট হবে।

## ডেপ্লয় (Vercel)
লাইভ লিংক: https://brsp-car-wash.vercel.app/
GitHub এ push করলেই Vercel অটো বিল্ড করবে (`vercel.json` আছে)।

## PWA
- মোবাইল/পিসিতে "অ্যাপ ইনস্টল করুন" বাটন বা ব্রাউজার মেনু থেকে Home Screen এ যোগ করা যায়
- অফলাইনেও রোস্টার দেখা যায়; নতুন ডেপ্লয় হলে অটো আপডেট হয়
- আইকন/ফেভিকন: `public/` ও `public/icons/`
- হেডারের অ্যানিমেশন: `src/assets/car-wash.gif`

## ফিচার
- রোস্টার কার্ড: PC ৩ কলাম • ট্যাবলেট ২ কলাম • মোবাইল ১ কলাম
- শিক্ষার্থী তালিকা ট্যাব: PC তে টেবিল (ছবির মতো), ট্যাবলেট/মোবাইলে কার্ড
- সব নাম বাংলায়; আইডি/তারিখ বাংলা বা ইংরেজি যেকোনো অঙ্কে সার্চ করা যায় (৮৮ = 88)
- নাম / আইডি / তারিখ / বার দিয়ে লাইভ সার্চ; নাম বাংলা বা ইংরেজি বানানে, আইডি ৮৮ বা 88 — দুইভাবেই মিলবে; ম্যাচ হওয়া সদস্য হাইলাইট হয়
- প্রিন্ট / PDF ডাউনলোড (ব্রাউজারের Print থেকে "Save as PDF")
- প্রিন্টে সার্চ ও বাটন অটো হাইড
- মোবাইল রেসপনসিভ
- WhatsApp এ এক ক্লিকে সাজানো ডিউটি-মেসেজ (তারিখ, সময়, সঙ্গীদের নাম ও WhatsApp নম্বর, সাইট লিংক — প্রিভিউ কার্ড ছাড়া)
- হালকা অ্যানিমেশন (কার্ড ফেড-আপ, হোভার লিফট; reduced-motion ও প্রিন্টে বন্ধ)
